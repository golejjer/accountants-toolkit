# Examplia general statutory pack (fictional example)

A complete example showing every feature of the pack format: questions, statutory accounts, a VAT with rate change, zero-rated, exempt, unrecoverable and reverse-charge codes, a turnover levy with gross-up and a sector-based fraction compounded into VAT, withholding at settlement, three returns, a pending change, and twenty worked examples.

**Everything in it is invented.** Use it only to see the format.

Check it with: `python scripts/validate.py assets/example-pack`
